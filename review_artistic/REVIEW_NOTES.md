# Художественная проверка — новая разлиновка THE CASE

Это **отдельная версия для художественного согласования**, а не утверждённая печатная раскраска. Основа — `review/` на 1501 область. Исходный `THE_CASE_ночные_фонари_19_красок.png` не изменён.

## Итоги новой автоматической сборки

- 902 связные окрашиваемые области и 902 номера в SVG.
- 0 областей без номера, 0 пикселей без назначения цвета, 0 обнаруженных разорванных областей.
- 19 исходных красок; обозначения 1–19; шрифт 5,3 pt, контур 0,2 мм.
- Fit-aware соединяет слишком мелкие цветовые островки с соседями, но **не создаёт карманы, кружки или прямоугольники под цифры**.
- Для глаз, уха, рта и центра сакуры есть отдельные тонкие печатные художественные линии, которые не являются окрашиваемыми областями.
- Общие векторные границы дополнительно смягчены на величину до 0,75 пикселя исходника.

## Остаточные риски

- При сравнении с исходной версией изменилось 18 792 пикселя (~1,78%) в широкой контрольной маске лица и переднего плана. Это измерение, а не основание утверждать полное сохранение деталей.
- **Визуальное художественное соответствие лицу и кимоно требует согласования.** Автоматический PASS подтверждает только нумерацию и технические условия; не заменяет художественный контроль.
- Технический отчёт: [audit.json](audit.json).
