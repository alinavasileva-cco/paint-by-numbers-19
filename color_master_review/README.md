# Ночные фонари · цветной мастер на согласование

Композиция по референсу `1000078518.png`. Лицо и пряди, заколки, цветы и складки кимоно, узоры на трёх передних фонарях и арка моста прорисованы в `artwork.svg`.

[Посмотреть цветной мастер](color-indexed.png)

- `palette.csv` содержит 19 красок в порядке образцов на референсе. Основной тон кожи — № 9, тёплый персиковый.
- `color-master.svg` содержит цветные поля с плавными общими границами.
- `color-indexed.png` содержит только 19 цветов палитры и сохраняет разбиение на поля.
- `audit.json` фиксирует проверку места для цифр при ширине изображения 388 мм и проверку дальнего глаза.

Сборка из корня репозитория с приложенным референсом и шрифтом Liberation Sans Regular:

```sh
python -m pip install -r night_lanterns_v11/requirements.txt
python color_master_review/build_color.py /path/to/1000078518.png ./color-output
```

Этот этап — цветное изображение для согласования. У полей предварительно проверено место для цифр кеглем 5,3 пт на контурном листе с линиями 0,2 мм.
