# «Ночные фонари» · второй этап

Векторная раскраска и цветной образец собираются из одной карты областей на листе 400 × 600 мм. Контур 0,2 мм, номера набраны Liberation Sans кеглем 5,3 пт. Все 19 цветов прочитаны из согласованного PNG.

Исходник для сборки — `Nochnye_fonari_etap_1_19_krasok_40x60.png`, SHA-256 `159d218a4f53a5e6f7676e0c621681bed8e55b06bb7d14c3de2eeca480810c72`.

Цвета сгруппированы по семействам. У тёплых оттенков и кремовых бликов однозначные номера, поэтому их легче разместить в небольших полях. Мелкие поля укрупнены с учётом соседних оттенков. В `detail-fields.svg` заданы локальные уточнения радужек, бликов глаз, нижней губы и сердцевин цветов по тому же мастеру.

## Сборка и проверка

Установите Liberation Sans Regular и зависимости из существующего `night_lanterns_v11/requirements.txt`. Сборка запускается из корня репозитория.

```sh
python -m pip install -r night_lanterns_v11/requirements.txt
python night_lanterns_stage2/build.py /path/to/Nochnye_fonari_etap_1_19_krasok_40x60.png /path/to/output
python night_lanterns_stage2/verify.py /path/to/output /path/to/Nochnye_fonari_etap_1_19_krasok_40x60.png
```

В `output/` сохранены векторный контур с номерами, цветная геометрия, палитра, карта номеров красок `labels.png`, карта идентификаторов `region-ids.png` и реестр `segments.json`. `audit.json` фиксирует проверку экспортированных PDF, в том числе толщину контура, кегль и отсутствие отдельных полей без номера.

В проверенном выпуске 973 области и 973 номера. Совпадение границ подтверждено для обоих печатных PDF.
